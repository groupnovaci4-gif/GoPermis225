# Images de l'application

Déposez ici vos propres photographies. Elles apparaissent automatiquement :
aucun code à modifier, il suffit de respecter les noms de fichiers.

**N'y mettez que des images dont vous détenez les droits** — photographies
prises par l'auto-école, images sous licence acquise, ou banque d'images libre
avec la licence conservée par écrit. Une image trouvée sur un moteur de
recherche n'est pas libre de droits.

| Fichier attendu | Où elle s'affiche | Format conseillé |
|---|---|---|
| `heros.jpg` | Vitrine — grande image d'accueil, à droite du titre | 1200 × 900, paysage |
| `conduite.jpg` | Vitrine — bandeau témoignage | 1200 × 800, paysage |
| `ville.jpg` | Vitrine — vignette « formés pour le trafic d'Abidjan » | 800 × 600, paysage |
| `connexion.jpg` | Page de connexion — panneau de gauche | 1400 × 1800, **portrait** |

Conseils :

- **Poids** : visez moins de 300 ko par image. Vos utilisateurs sont souvent en
  données mobiles ; une photo de 4 Mo rend la page inutilisable sur le terrain.
  Redimensionnez avant de déposer.
- **Format** : `.jpg` pour les photographies, `.png` seulement pour un logo ou
  un dessin à fond transparent. Le `.webp` fonctionne aussi si vous l'avez.
- **Cadrage** : les images sont recadrées automatiquement pour remplir leur
  emplacement (`object-fit: cover`). Le sujet doit être au centre, et la photo
  de connexion doit supporter un cadrage vertical.

Si un fichier est absent, l'emplacement affiche le dégradé de repli — la page
reste correcte, elle n'a simplement pas de photo.
